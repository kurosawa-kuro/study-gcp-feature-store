# アドオン2: BigQuery内特徴量生成パイプライン

## 目的

BigQuery上に存在する検索ログ、PVログ、カートログ、物件マスタなどの複数テーブルから、Feature Store投入用の特徴量テーブルを生成する。

本アドオンでは、外部DB連携やモデル学習は対象外とし、BigQuery内でのデータ収集・結合・集計・欠損補完・特徴量テーブル作成を検証する。

## 位置づけ

```text
BigQuery raw / master tables
  ↓
BigQuery SQL
  - JOIN
  - 集計
  - 欠損補完
  - 期間集計
  - feature_timestamp付与
  ↓
BigQuery feature table
  ↓
Vertex AI Feature Store
