# Feature Store 後段アドオン仕様

> **ステータス: ✅ 実装済み + 実 GCP 動作検証済み（bq / online 両モード）（2026-05-20 / mlops-dev-a）**。実装計画・検証結果は [アドオン1実装計画.md](アドオン1実装計画.md)。

## 1. 結論

本プロジェクトでは、Vertex AI Feature Store への登録・同期で終わらせず、**Feature Store から特徴量を取得し、CSV / GCS へ出力する後段処理を追加する**。

ただし、モデル学習・推論API・Endpoint デプロイまでは実装しない。

今回の追加スコープは以下とする。

```text
Feature Store
  ↓
Feature View sync
  ↓
特徴量取得確認
  ↓
CSV出力 / GCS出力
  ↓
簡易 downstream 利用確認

※ モデル学習はしない
※ Endpoint は作らない
※ 推論APIは作らない
